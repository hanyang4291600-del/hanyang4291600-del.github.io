使用规则

  1. 每家 AI 单独问、单独记、单独下结论；一家的结果不判另一家。
  2. 记录 7 字段：日期 / 平台 / 问法原句 / 是否联网 / 回答原文 / 回答层 0~4 级 / 来源链接 URL。
  3. 三态 有 / 无 / 未检测·无法确认；未检测 ≠ 未收录。
  4. 回答层与索引层分开记，两层都有证据才说「被收录并被推荐」。
  5. 无基线不说提升；单次查询不当证明；AI 版本更新后重测基线。
  6. 轻量版默认一次基线 + 一次间隔复测，标「样本少，仅供参考」；完整版需 ≥3 时间窗口、单一指标 ≥30 次有效观测。
